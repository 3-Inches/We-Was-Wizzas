# Audit 2: everything since the last Fable pass, and the toolkit's own writing

> A working document, kept in the repository so that it survives between sessions. It lists findings to fix. Nothing in it has been acted on yet. Delete this file once its items are closed.

Read-only. Nothing was changed. Paths are under `app/`; book lines are line numbers in the markdown files in `reviewed/` and `wip/`.

**Scope.** The last Fable pass ended with commit `07653a7` (PR #47). This covers what came after: the core-book check (PR #48), *The Mysteries* (#49), *Realms of Power: Faerie* (#50), and Hedge Magic's six traditions, *Hermetic Projects* and *The Church* (#51). That is 99 files and about 14,000 added lines, of which roughly 6,000 are hand-written engine and interface code. The second half reviews the toolkit's own text: the Guide, the tutorials, the rules-check messages, card labels and the README.

**How it was checked.** Each new engine module was read against its chapter, starting from the book's formula lines and worked examples. Each new Game Table page was opened in the browser with every card unfolded (fixtures from the build sessions). The written text was read in samples and measured by script.

**Status words.** *Confirmed* = read directly in the code and in the book. *Likely* = read in the code, and the book supports it, but the book's wording leaves room.

**Overall.** The formulas are right almost everywhere: I found seven places where the app and a book disagree, and none of them corrupts a sheet. The larger problems are in how the new work is reached and explained: season work that the Seasons page does not know about, no tutorial or Game Mechanics pointer for anything added since the last pass, and a Guide and README that have grown into inventories only someone who already knows the rules can read.

## A. Fix these (the app and the book disagree)

### A1. Negative Sympathy Traits give the wrong number of botch dice — confirmed
- RoP:F line 5846: a negative Sympathy Trait gives "a number of additional botch dice equal to the character's worst Trait on all botch rolls" (Iron −3 means three more dice, on every botch roll the character makes).
- `src/ui/pages/FaeriePart.tsx:115` (rites) and `:279` (bargaining) add one die for each negative trait *ticked* (`.filter(score < 0).length`). A character with Iron −3 gets one die, and none unless Iron is ticked.
- `src/ui/character/SympathyCard.tsx:25` tells the player the same wrong thing: "adds a botch die".
- The general Roll page (`DicePage.tsx`, RollPart) does not know about Sympathy Traits at all, so the dice are never added to ordinary rolls.
- Fix: one helper, `sympathyBotchDice(c)` = the absolute value of the worst negative trait. Use it in both faerie cards whatever is ticked, add it to the Roll page's botch dice with a line saying why, and correct the card's sentence.

### A2. A botched Vision spell should give double Warping Points — confirmed
- HMRE line 3723: "every Vision botch inflicts double the normal Warping Points".
- `src/ui/pages/GruagachPart.tsx:260` adds `botches` for every Form.
- It matters beyond the count: with doubling, a single botch on a Vision spell is 2 points, which calls for the transformation roll (`transformationFollows`).
- Fix: double the points when the spell's Form is Vision, before the transformation check, and say so in the result line.

### A3. A gruagach's known spell can never botch unless vis is spent — confirmed
- `GruagachPart.tsx:232`: `const stress = mode === 'spontaneous' || vis > 0`. A formulaic spell is always a simple die otherwise.
- The learned magician's charm card has a "stress die" tick for exactly this (`HedgePart.tsx`, near line 229).
- Fix: the same tick on the gruagach card, on by default, with the same hint.

### A4. A sympathy botch takes one experience point however many zeros came up — confirmed
- RoP:F line 5852: "For each 0 rolled as a botch … the character loses an experience point in each applicable Trait."
- `FaeriePart.tsx:152` and `:297` call `xp(used, -1)` once.
- Fix: pass the botch count.

### A5. The numerologist's rote limit is rounded the wrong way — confirmed
- TMRE line 3683: the Rote Lab Total ÷ 5, "round up". `src/engine/hermeticMysteries.ts:233` uses `Math.floor`. A Lab Total of 28 shows "up to level 5"; the book gives 6.
- TMRE line 3679: the Arithmetic bonus to the Rote Lab Total is "limited by Magic Theory". It is added uncapped (`:232`).
- Fix both, and add the two cases to `hermeticMysteries.test.ts`.

### A6. Elementalist Refining: a third case and two limits are missing — confirmed
- **A being's Might** (HMRE line 1332). The book has three cases: the being's own element restores Might, the opposed element drains it, and *any other* element does half (rounded down). `refineMight` (`src/engine/elementalMagic.ts`) and the card's sentence offer only the first two. Vis forms only when the being overflows its pool or loses Might, not on every restore. Add an "element is: its own / opposed / another" choice and compute from it.
- **The longevity potion's vis** (line 1306): "an elementalist can only spend as much vis as the sum of his scores in the Elementalist Forms." The card never compares the two. In the fixture the potion needs 9 pawns and the limit is 10, so it happens to fit; with Forms one point lower it would be impossible and the card would still offer it. Compare `potion.vis` with `elementalVisLimit(d)`; warn and disable.
- **Theurgical Refining** adds the Lore of the *target's* realm (line 1340). The card has no realm choice and always uses the default.

### A7. Incompatible Hedge Arts is enforced for gruagachan but not for learned magicians — confirmed
- The Flaw is in both chapters (HMRE line 4352 for learned magicians). `gruagach.ts` notes it in the Casting Score; `learnedMagic.ts` `castingScore` and `learnedLabTotal` do not look for it.
- Fix: the same check in both learned totals, and leave the barred pair out of the card's lists.

## B. Rules points that are smaller, or where the book is unclear

1. **Entreat the Powers with several realms** (HMRE line 4571). When the aura's own realm is among those called, `entreatTotal` divides nothing. The book says the totals "of the different realms" are added, which reads as: the native realm's Lore counts in full and each foreign realm's is divided. *Likely.* Low priority; worth a comment either way.
2. **Entreaty is spoken aloud** (line 4565: no Quiet Magic, no silent casting). The card does not say so. One clause in the hint.
3. **Latin 1 to learn charms** (line 4141). The rules check asks for Artes Liberales 1 but not Latin 1.
4. **Moving vis** (line 1326). The text says half is lost, rounded down (5 pawns → 3 arrive); the book's own example says 5 → 2. `moveVis` follows the text. Say which in a comment, or follow the example, which is usually what the author meant.
5. **Summoning chart.** `summoningReach` reports the chart row's Might (a total of 7 says "Might 5") while `summoningNeeds` lets Might 7 through. Report `min(total, row above)` so the sentence and the test agree.
6. **Vitki: hiding runes at no penalty** (line 6441: twice the time and Dexterity + Craft: Runes of 6+ on a simple die). Only the −2 and −5 penalties are offered.
7. **Tattoos** (`GruagachPart.tsx:342`). The line states the material's capacity (2 × size) but nothing compares it with the pawns needed, nor the pawns with the season's limit (twice Pictish). Uses a day are fixed at 1; the book's example (line 3059) spends its spare level on 2 a day.
8. **Poetic justice** (lines 3256–3270): the −6 to +9 modifier on the victim's Stamina roll against a geas or curse is not on the card. A six-row list beside the result would do.
9. **A gruagach spell invented over several seasons** is not tracked ("note the points on the season", `GruagachPart.tsx:366`), while a learned magician's is (`inventSeason`). Track it the same way.
10. **Negative Sympathy Traits and the Warping Score** (RoP:F line 5850): a negative trait can be raised by experience only while the Warping Score *exceeds* its absolute value. `sympathyXp` caps only positive traits.
11. **Medicinal Refining for someone else** (HMRE line 1310): the physician can make the longevity potion for another person, and a Characteristic potion (line 1312). The card always uses the elementalist's own age and sheet, and the Characteristic potion falls under "another refining". A gap, not an error.
12. **Mythic Herbalism and Mythic Alchemy** (HMRE lines 4161–4267) are Abilities with no card. A gap; the herbalism table is small and self-contained if you want it.

## C. How it is used

### C1. Season work that the Seasons page does not know about — the most important one here
- The new season-long work lives on the Dice page: "A season in the kitchen", "A gruagach's season", "A season of Refining", "A season of charms", "Make an amulet", "A vitki's season" (all under Dice › Hedge magic), and pilgrimages and Devotions under Faith & miracles.
- The Seasons page (Plan, Execute, Resolve) is where every other season is spent. It has no mention of any of them: no hedge reference in `SeasonsPage.tsx` or `SeasonPlanner.tsx`.
- So a folk witch's player planning Spring on the Seasons page sees only the general choices, and has to know to leave for Dice › Hedge magic to brew. The cards do refuse a season already spent, so nothing is corrupted, but the path is hidden.
- Change: on the Seasons planner, when the character has such work, show a line with a link ("This character's own magic: brew potions, enchant a tattoo… ›" going to the right card with the character chosen). Better still, list those works among the season's choices and open the card from there. Hermetic lab work already works this way.

### C2. Vis for hedge lab work is typed in, not taken from the stores
- Hermetic lab projects draw vis from the character's purse and the covenant's stores. None of the new pages do (only `LabProjects.tsx` touches the vis stores).
- The folk witch card asks for "Vis on hand" as a number, 10 by default (`FolkWitchPart.tsx:156`), and ends "Take the vis from the stores by hand." The elementalist card says the same; the gruagach's tattoo and the amulet say nothing.
- Change: read what the character and covenant hold, take it when the season is worked, and refuse when it is short, as the Hermetic lab does. Until then, one consistent sentence on every such card.

### C3. Pickers that do nothing until a second button is pressed
- "Write a charta", "Make an amulet" (`HedgePart.tsx:282`) and "A gruagach's season" (`GruagachPart.tsx:402`): choosing a charm or spell in the list changes nothing until **Use this effect** is pressed. The "Effect:" line below keeps showing the previous one, and the Lab Total is for the previous one.
- Change: apply the choice as it is made when it comes from the book's list; keep a button only for the "from a guideline" design, where there are several fields to fill first.

### C4. Creation settings shown at the table
- The sheet cards for each tradition are also rendered at the bottom of the Dice page: "Learned magic" (years under a master, training experience), "Folk witch", "Gruagach", "Vitki" (`HedgePart.tsx:119–140`). For a finished character, "Years of apprenticeship" and "0 of 200 experience spent" are noise there, and each repeats a full charm or spell picker a third time on the page.
- Change: at the table show only the list of what is known (with "add one learned in play"); keep the apprenticeship budget on the sheet and in the builder.

### C5. Cards that open on a warning
- The faerie rite and bargaining cards start with no Sympathy Trait ticked, so the first thing shown is "Its level is above what the chosen traits allow" (or "This faerie's Might is above…") and a disabled button.
- Change: lead with the instruction ("Tick the Sympathy Traits that fit this effect"), show the warning only after a trait is ticked, and tick the trait for the player when they have only one.

### C6. Faith & miracles has grown to nine cards or more, shown to everyone
- The three Church cards show for every character, including a pagan nightwalker. "The mystic's path" prints an amber "Needs a positive Pious…" sentence, and its buttons work all the same.
- Change: show a path only to a character who can walk it, or fold it with the reason as its summary line ("Not open to Bálint: no Pious trait"). Consider folding the season-scale cards (Devotion, Pilgrimage, the paths, Rites) by default, so the top of the page is what is rolled in a scene.

### C7. Numbers the player has to know already
- Folk witch power: "Ease Factor — As the Ability's own rules (ArM5) set it" (`FolkWitchPart.tsx:116`). The book gives tables for Cursing and Healing, and the data already has the healing one. Offer the Ease Factors as a list for each power, with free entry as the last choice.
- Elementalist: "Type of target" offers Medicinal, Philosophical, Theurgical with no gloss (`ElementalPart.tsx:103`). One line each: bodies and their humors; natural things and animals; elemental spirits.
- Divination: "Method" is a flat list of 34 names (Alectryomancy, Ooscopy…), glossed only after choosing. Put the gloss in the option: "Ooscopy (eggs)".
- Vitki: both rune lists show all 24 runes with "(0)". Put the runes with a score first and mark those not opened.
- Faerie rite: Range, Duration and Target lists are 11, 21 and 15 long, Hermetic and faerie mixed. Group them under two headings.

### C8. Things the app could do for the player
- **The Witch Moon** is started by a button ("Begin the Witch Moon (a new Warping Score)", `FolkWitchPart.tsx:371`). The app knows when a folk witch's Warping Score rises; prompt then, as Twilight is prompted. The same goes for Nátt-thel (two or more points at once) and Faerie Calling.
- **Sympathy Traits on ordinary rolls.** The card says a trait can stand in for a specialty, but the Roll page offers no way to apply one; the player adds a number by hand and has to remember it forces a stress die. Add a tick per trait on the Roll page for a character who has them (this also carries A1).

### C9. The same act, worded five ways
- "Work the season", "Work a season", "Refine (a season)", "Make it (a season)", "Learn them (a season)". Pick one pattern, for example the verb and then the cost: "Brew (a season)", "Enchant the tattoo (a season)".
- "The chapter's other rolls" (`NightwalkerPart.tsx:78`, and the Guide, `HelpPage.tsx:411`) names the book, not the play. "Other rolls of the night".
- Faerie page header: "a Faerie effect here takes the aura as +2" → "Faerie aura here: +2 to faerie effects."
- Church: "Integrated. Choose one: …" is followed by a single option when only one applies; and "Divine Gloom" and "Divine Ascent" are used with no explanation (`ChurchPart.tsx:212, 262`). Half a sentence each.

### C10. Where Great projects lives
- The "Great projects" card (a mason's building, a menagerie) is on Possessions, for whoever's possessions are shown. A player raising a tower will look on the covenant or on Seasons. A link from the covenant page, or moving the building half there, would help; the menagerie half is closer to the covenant's creatures than to a character's belongings.

## D. The toolkit's own writing

The short text is good. The long text has outgrown its form.

### D1. What is good, and should be the model
- **Rules-check messages** are short, say what is wrong, and most say how to fix it ("Virtues cost 12 points but Flaws only provide 10."). Three to touch: "A score of 10 in a rune is the practical most just out of apprenticeship" (`validate.ts:91`; say "is about the highest a vitki has straight out of apprenticeship"); the Magic (Being) Companion message, which quotes the book mid-sentence; and "(Te + Fo + Int + …)", which should spell the words out.
- **Tutorial steps** explain before they instruct. "It keeps what their work builds up in Labor Points: not money, but the time and effort put into the business" is exactly the voice to use everywhere.

### D2. The Guide reads as an inventory — measured
- 9,431 words in 104 blocks. 13 blocks are over 150 words; 17 contain a sentence over 60 words; the longest sentence is **247 words** (`HelpPage.tsx:357`, the Game Table bullet, with brackets inside brackets).
- The entries added since the last pass (Faerie, the six traditions, The Mysteries, The Church, Hermetic Projects) are written as lists of features for someone who knows the book. Example, as it stands:
  > **Elementalists** (*Hedge Magic, Revised Edition*): the Virtues of the four Techniques (each for a type of target: Medicinal, Philosophical or Theurgical) and the four Elementalist Forms open them at 0. The sheet shows the **Elemental Traits** that Warping and the Forms bring. On **Dice › Hedge magic**: Summoning, Controlling and Divining rolled with the elements and vis chosen, and what the total reaches; and a season of **Refining**…
- The same entry written for someone who does not know the rules:
  > **Elementalists** work magic through the four elements. (*Hedge Magic, Revised Edition*.)
  > 1. **Make one.** Give the character at least one Technique Virtue (Summoning, Controlling, Divining or Refining) and one Form Virtue (Air, Earth, Fire or Water). Each starts at 0.
  > 2. **Use the magic.** Go to Game Table › Dice › Hedge magic. Choose the Technique and the elements, then roll. The card says what the total can affect.
  > 3. **Spend a season.** The Refining card on the same page makes a longevity potion or draws vis from an aura.
  > 4. **Watch the Warping.** As it grows, the character takes on the elements' temperaments. The sheet lists them and what they do.
- Change, for the whole Guide: one idea to a sentence; no brackets inside brackets; the order *what it is, how to start, where to play it*; and move complete lists (every Hook, every modifier) out of the Guide, since the card itself and Game Mechanics already hold them. A fair target is half the present length.

### D3. The README is 123,000 characters
- `app/README.md` is 326 lines. Fifty lines are over 600 characters. Line 18, the **Dice** bullet, is **11,495 characters** in one paragraph. Nobody reads that on GitHub, and it repeats the Guide.
- Stale lines in "Not yet automated":
  - Line 263 says the Mystery Cults' casting systems (Numerology, Celestial Magic, Synthemata…) "and of the hedge traditions are reference only". Both are now built.
  - Line 276 lists pilgrimages as not automated. They are tracked.
- Change: a README of about a page: what it is (the present first two paragraphs are right), how to run it, a table of *area → what it does in one line → the book*, then "Not yet automated", then how it is built. Move the detail into `docs/` by area, or drop it in favour of the in-app Guide. Keep "Not yet automated" current, since it is the part people act on.

### D4. Tutorials
- 169 steps, 59 words on average. 52 steps are over 70 words. The City & Guild tutorial has steps of 130 to 183 words (`tours.ts:850–930`), which fill a phone screen and hide the control they point at. Split each into two or three steps; the content is right.
- Stale: "the sidebar lists its pages: the overview, Seasons, the Market, the covenant and every character, then the Tools" (`tours.ts:156`). The sidebar is now Saga Overview, Game Table, Covenants, People, The Tribunal, then Tools and Reference; Seasons and the Market are pages of the Game Table.
- The toolkit tour's "Dice" step does not mention the page's newer parts (Faith & miracles, Faerie, Hedge magic, Mysteries), and the code comment at `DicePage.tsx:70` still says "in four parts"; it has seven.

## E. Missing coverage

### E1. No tutorial for anything added since the last pass
- `src/ui/tour/tours.ts` has not changed since `65d124a`. There are 18 tutorials; none covers Faerie, any hedge tradition, the Mysteries' table cards, The Church or Hermetic Projects. The Divine has one, and it is the pattern to follow: a practice character, and a step for each card.
- Suggested, in order of use: (1) one "Hedge magic" tutorial that follows whichever tradition the chosen character has, since the six pages share a shape: who, the aura, cast or use, a season's work, the tradition's Warping; (2) "Faerie wizards"; (3) a short "Mysteries at the table". The Church and Hermetic Projects need a step each added to the Divine and laboratory tutorials, not tutorials of their own.

### E2. Game Mechanics does not point to the new pages
- The Game Mechanics page has topics for all of this: `hedge-magic`, `elementalists`, `folk-witches`, `gruagachan`, `learned-magicians`, `nightwalkers`, `vitkir`, `faerie-wizards`, `faerie-characters`, `pilgrimage`, `hermetic-alchemy`, `hermetic-astrology`, `divination-and-augury`, `hermetic-theurgy`.
- `src/data/appPlaces.ts` has no "In the app" pointer for any of them (the file is unchanged since the last pass). The tutorial promises that pointer: "**In the app** says where the toolkit does each one."
- `the-church` (`appPlaces.ts:137`) still points to the sheet ("Overview → Society → Petition the Church", "Plan a season (Worship)"), from before play moved to the Game Table.
- Fix: add the pointers (Dice › Hedge magic and so on) and correct the Church's. `appPlaces.test.ts` already checks the ids are real.

## F. Smaller

1. **Typos carried in from the scans**, visible in lists: "Eeavesdrop with the Eyes", "subterfude", "Skin of the Doppleganger" (`data/gruagachSpells.ts:104–107, 89`); learned charm names in broken title case, "Stay The Fickle Hand Of Fate" (`data/learnedCharms.ts:123`) beside the same charm correctly cased once learned. The gruagach in the fixtures is "Dombnall", the scan's misreading of Domhnall (HMRE line 324 has it right; lines 2841 and 3059 do not). Worth correcting in `reviewed/` too.
2. **Vis in a charm or spell** has a stepper to 20 with no limit applied and nothing taken from a stock. This matches Hermetic spellcasting in the app, so it is a convention, but the hint could say "take it from the purse by hand".
3. **A template character's native language** falls back to French when the saga has no Tribunal (`engine/templates.ts`). Ask, or leave "Native Language" for the player to set.
4. **"Abandon"** on a pilgrimage or a Spiritual Path is a bare text button. Undo covers it, but it sits beside "Add" and is easy to hit; give it the look of the other destructive buttons.
5. **The hedge page's aura controls** show for a nightwalker, whose card does not use the aura.
6. `sympathyStep` (`faerieWizardry.ts`) contains `Math.abs(s < 0 ? s : s)`, a ternary that does nothing. Harmless; tidy it.
